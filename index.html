Install as App

MatchAdda ko apne phone par app ki tarah install kar sakte ho.

Android Users

Chrome mein site kholo, top-right menu open karo, phir "Install app" ya "Add to Home Screen" tap karo.

Done! Home screen par MatchAdda app icon dikhega aur native app ki tarah chalega.

iPhone/iPad Users

Safari mein site kholo, Share button tap karo, phir "Add to Home Screen" select karo.

Phir app name likho aur add karo. Home screen par install ho jayega!

Desktop Users

Chrome, Edge, ya Brave mein site kholo. Address bar mein + icon dikhe to "Install MatchAdda" click karo.

Native desktop app ki tarah khul jayega!

Offline Support

Internet ke bina bhi chalega! Ek baar app install hone ke baad, schedule, teams, points table sab offline mein bhi dekh sakte ho. Updates automatic download ho jayenge jab internet aa jaye.
